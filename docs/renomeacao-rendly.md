# Renomeação do repositório para Rendly

A renomeação está condicionada à revisão do PR e à autorização posterior. Nenhum repositório novo é necessário.

Após a autorização, acessar **Mateus1804/controle-financeiro-android → Settings → General → Repository name**, informar **Rendly** e selecionar **Rename**. O destino será `https://github.com/Mateus1804/Rendly`.

Preservar histórico, issues e PRs. Conferir redirecionamentos, permissões, Actions e badges. Atualizar o remote com `git remote set-url origin https://github.com/Mateus1804/Rendly.git` e testar fetch/push e CI. Não alterar applicationId, namespace, assinatura, Room ou identificadores do formato de backup.
